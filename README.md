# NutriLog 5.0

Paste lines like:
2026-10-19 08:30 Breakfast (Banica & Yogurt): 1446 kcal | P 46.4g | C 137.6g | F 78.0g | Fiber 4.2g | Na 900mg

## New in 5.0
- Log: "Copy prompt" gives any AI the exact format; "Paste" extracts valid lines from messy text.
- Diary: Edit an entry in place (same line format).
- Stats: Overview, Weight vs calories (judged against Cutting/Maintaining/Bulking, suggests a calorie goal),
  Weekly report (lowest nutrients, food ideas, over-limit nutrients).
- Smart reminders: skip when the meal is logged / you just ate / goal reached; Log now and Snooze buttons.

## Updating
Same signing key + rising version code: install the new APK over the old one and Android updates it in place.

## Build
GitHub: Actions > Build APK > Run, then download from Releases. Or Android Studio: Build > Build APK(s).
