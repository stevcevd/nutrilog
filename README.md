# NutriLog 5.2

## New in 5.2
- Stats count finished days only; days under 40% of that day's calorie goal are skipped; today is shown as "so far".
- Goal history: each day is judged against the goals that applied on that day. Changing goals never changes the past.
- Weight vs calories only uses the current phase (cutting/maintaining/bulking) and marks where you switched.
- Me: workouts show which app recorded them; tap for details and "Open <app>".
- Themes: 10 colour themes, each with light and dark looks (Settings > Themes).

## Updating
Same signing key + rising version code: install the new APK over the old one and Android updates it in place.
